## 📌 نبذة عن المشروع (Project Overview)

يهدف هذا المشروع إلى تصميم وتطوير نظام ذكي متكامل يمكن ارتداؤه على المعصم، يقوم بقراءة إشارات الحركة اللحظية من مستشعر القصور الذاتي ذي الـ 6 محاور (**MPU6050 IMU**) المتصل بمتحكم دقيق (**ESP32**)، وتحليل البيانات التسلسلية الزمنية باستخدام خوارزميات وشبكات **تعلم الآلة والتعلم العميق (MLP & 1D-CNN)**، ومن ثم ترجمة الإيماءات الحركية لليد بدقة عالية إلى أوامر تحكم فورية لعروض **Microsoft PowerPoint** وتطبيقات سطح المكتب دون الحاجة لفأرة أو لوحة مفاتيح أو أجهزة تحكم تقليدية.

النظام يعمل محلياً بالكامل على الحاسوب الشخصي (Edge/Local Inference) عبر المنفذ التسلسلي السلكي (USB Serial) بدون أي اعتماد على خدمات سحابية أو اتصال بالإنترنت، مما يضمن زمناً حقيقياً منخفضاً جداً وأماناً وموثوقية عالية أثناء العرض.

## 🚀 مسار تدفق البيانات والنظام (End-to-End Pipeline)

```text
حركة يد المستخدم (Hand Motion)
      ↓
مستشعر MPU6050 (تسارع وزوايا دوران 50Hz) + زر زناد (Button Trigger)
      ↓
متحكم ESP32 يرسل الإشارات المقاسة عبر المنفذ التسلسلي (USB Serial 115200 Baud)
      ↓
تطبيق سطح المكتب بلغة Python (يلتقط نافذة زمنية بطول 51 عينة ≈ ثانية واحدة)
      ↓
معالجة الإشارات والتطبيع الإحصائي (Z-Score Normalization)
      ↓
فحص جودة الحركة وتصفية الطاقة الحركية (Motion Energy & Quality Filter)
      ↓
النموذج الذكي (1D-CNN أو MLP) يصنف الإيماءة ويحدد مستوى الثقة (Confidence)
      ↓
آلة الحالات لمنع التكرار (Intent Capture State Machine & Dwell Protection)
      ↓
محاكي لوحة المفاتيح الآمن (PowerPoint Slideshow Control)
      ↓
تنفيذ الأمر: الشريحة التالية، الشريحة السابقة، بدء العرض، الشاشة السوداء، أو الإلغاء
```

## 🖐️ جدول الإيماءات وأوامر PowerPoint المدعومة (Supported Gestures & Commands)

| الإيماءة (Gesture) | الفئة المعيارية (Canonical Class) | أمر PowerPoint المقابل (PowerPoint Command) | مفتاح التحكم (Key Simulation) |
| :--- | :--- | :--- | :--- |
| **إمالة اليد لليمين** | `right` | الشريحة التالية (Next Slide) | سهم يمين `Right` |
| **إمالة اليد لليسار** | `left` | الشريحة السابقة (Previous Slide) | سهم يسار `Left` |
| **إمالة اليد للأعلى** | `up` | بدء العرض من الشريحة الأولى (Start Slideshow) | `F5` |
| **إمالة اليد للأسفل** | `down` | تعتيم الشاشة / شاشة سوداء (Toggle Black Screen) | `B` |
| **هز اليد السريع** | `shake` | إنهاء العرض التقديمي (End Show / Escape) | `Esc` |
| **وضع الثبات / السكون** | `still` | وضع محايد / استقرار اليد (Neutral Resting) | لا يوجد أمر (No Action) |

## 🛠️ العتاد الصلب والمكونات الإلكترونية (Hardware Specifications)

* **المتحكم الدقيق (MCU):** ESP32 NodeMCU (Dual-Core Tensilica Xtensa 32-bit).
* **مستشعر الحركة (IMU):** MPU-6050 (مستشعر تسارع 3 محاور ومستشعر سرعة زاوية 3 محاور).
* **بروتوكول الربط الداخلي:** I2C Bus عبر المنافذ:
  * خط البيانات `SDA` $\rightarrow$ GPIO 21
  * خط التردد `SCL` $\rightarrow$ GPIO 22
* **زر زناد أخذ العينات:** Push-Button متصل بالمنفذ GPIO 4 مع مقاومة رفع داخلية ومكافحة اهتزاز برمجية (Debounce).
* **معايير القياس الحساسة:**
  * التسارع (Accelerometer): مدى $\pm 2g$ (معامل التحويل: القراءة الخام $\div 16384$).
  * الجيروسكوب (Gyroscope): مدى $\pm 250^\circ/\text{s}$ (معامل التحويل: القراءة الخام $\div 131$).

## 🧠 النماذج الذكية وهندسة البرمجيات (Machine Learning Architecture)

يتضمن المشروع نموذجين متكاملين تم تدريبهما على بيانات الإيماءات الحركية:
1. **شبكة الطي أحادية البعد (1D Convolutional Neural Network - 1D-CNN):**
   * مصممة خصيصاً لاستخراج العلاقات الزمنية بين محاور التسارع ومعدلات الدوران الستة.
   * مدخلات النموذج: نافذة بحجم $(51, 6)$ أي 306 قياسات حساسة لكل إيماءة.
   * تحقق دقة تمييز عالية جداً في البيئات الحية بفضل طبقات `Conv1D` و `MaxPooling1D` و `Dropout`.
2. **الشبكة العصبية متعددة الطبقات (Multi-Layer Perceptron - MLP Baseline):**
   * نموذج أساسي سريع مبني باستخدام `scikit-learn` يمرر مصفوفة مسطحة بحجم 306 ميزة لتصنيف فوري.
3. **آلة حالات النوايا لمنع التكرار العرضي (Intent Capture State Machine):**
   * تعالج مشكلة تكرار الأوامر إذا استمر المستخدم في إمالة يده؛ حيث تتطلب عودة اليد للوضع المحايد (`still`) قبل قبول أي أمر جديد.
4. **نظام فحص جودة الإشارة (Motion Quality & Dynamic Energy Rejection):**
   * يرفض القراءات المشبعة، الحركات الضعيفة جداً، والحالات التي يكون فيها فارق الثقة بين الفئتين الأوليين ضئيلاً ($< 0.20$).

## 💻 واجهة سطح المكتب الهندسية الحديثة (Engineering Desktop GUI)

يحتوي المشروع على واجهة رسومية تفاعلية حديثة (`src/gui_app.py`) مصممة خصيصاً لمناقشات مشاريع التخرج والعروض التوضيحية:
* **راسم إشارات متذبذب حي (Vector Oscilloscope):** يرسم محاور التسارع والسرعة الزاوية الستة بشكل فوري.
* **شريحة عرض توضيحية مدمجة (Integrated Slide Preview):** تتيح للمقيمين تجربة تقليب الشرائح وتشغيل العرض مباشرة داخل التطبيق دون الحاجة لفتح PowerPoint خارجي.
* **بطاقات حالة التصنيف والتحكم المنفصلة (Decoupled Cards):** تعرض الفئة المتوقعة، نسبة الثقة، حالة آلة الحالات، ونوع الأمر المنفذ.
* **محدد المنافذ والتشغيل التجريبي الآمن (Safe Dry-Run Mode):** يتيح إعادة تشغيل ملفات CSV واختبار النماذج بالكامل دون اتصال العتاد وبأمان كامل.

## ⚙️ متطلبات التثبيت والتشغيل (Setup & Execution)

### 1. إعداد البيئة الافتراضية وتثبيت الحزم (Environment Setup)

افتح نافذة PowerShell أو موجه الأوامر في مجلد المشروع، ثم نفذ:
```powershell
# إنشاء البيئة الافتراضية المخصصة
py -3.12 -m venv .venv

# تفعيل البيئة وتثبيت الحزم المعتمدة
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 2. تشغيل واجهة التحكم الرئيسية (Launch Desktop Application)

يمكن تشغيل التطبيق بإحدى الطرق التالية:
* **الطريقة السريعة:** النقر المزدوج على ملف `run_app.bat` في نظام Windows.
* **عبر موجه الأوامر:**
  ```powershell
  .\.venv\Scripts\python.exe main.py
  ```

### 3. تشغيل حزمة الفحص الآلي والاختبارات (Run Verification Tests)

للتحقق من سلامة كافة مكونات المعالجة والاستدلال وآلة الحالات بدون الحاجة لحساسات:
```powershell
.\.venv\Scripts\python.exe -m unittest discover tests
```

### 4. تجربة الاستدلال عبر محاكي إعادة التشغيل (Offline CSV Replay Demo)

لاختبار التمييز الفوري للإيماءات عبر ملفات البيانات المسجلة مسبقاً:
```powershell
# تشغيل الاستدلال عبر شبكة 1D-CNN
.\.venv\Scripts\python.exe src/replay_demo.py --dataset data/raw_new/ --model cnn --limit 12

# تشغيل الاستدلال عبر نموذج MLP
.\.venv\Scripts\python.exe src/replay_demo.py --dataset data/raw_new/ --model mlp --limit 12
```

## 🔬 خطوات دمج وتشغيل العتاد الصلب (Hardware Integration Steps)

عند توفر الحساسات والمتحكم، يتم تطبيق الخطوات التالية:
1. **برمجة ESP32:** افتح ملف `firmware/imu_remote.ino` عبر برنامج **Arduino IDE** واضبط الباود على `115200`، ثم ارفع البرنامج إلى المتحكم.
2. **فحص الإشارات:** تأكد من ظهور رسالة النجاح `# MPU6050 initialized successfully` وظهور إشارة `# BUTTON_PRESSED` عند الضغط على الزر.
3. **جمع بيانات تدريب إضافية (اختياري):**
   ```powershell
   py -3.12 src/logger.py --port COM3 --gesture tilt_right --trial 1 --num-trials 20
   ```
4. **التشغيل الحي والتحكم الفعلي:** افتح التطبيق، اختر منفذ `COM` المناسب، وعطّل خيار `Dry Run` لتوجيه أوامر المفاتيح الفعلية إلى PowerPoint.
